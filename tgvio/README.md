# TGVIO 版 OpenList

本分支（`tgvio`）= 官方 OpenList v4.2.6 + 为 TGVIO 适配的少量补丁。原二开（缩略图、代理节点池、多根挂载）已移除；`main` 分支仅作历史参考。

## 补丁

| 提交 | 内容 | 原因 |

## 接口

| 接口 | 权限 | 内容 |
|---|---|---|
| `GET /api/tgvio/stats` | 已登录、非访客 | 启动时间与运行时长（崩溃后会重置）、计数器（`115_calls:*`、`115_405`、`115_connect_*`、`link_cache_hits/misses`、`115_upload_*`）、熔断状态、网盘空间（缓存 10 min） |
| `GET /api/admin/tgvio/recycle?offset=&limit=` | 管理员 | 115 回收站一页（≤1000 项）及其大小 |
| `POST /api/admin/tgvio/recycle/clean` `{"ids":[...]}` | 管理员 | 永久清理 1–1000 个指定条目，绝不清空整个回收站 |

## 前端

默认嵌入 `tgvio-web/` 里的自研前端（React + Vite + Tailwind v4 + Motion），与官方 OpenList-Frontend 无代码关系，只用 OpenList 的 HTTP API。代码地图与约定见 `tgvio-web/README.md`。

- 文件：网格/列表（虚拟滚动，1500+ 项流畅）、进入文件夹的纵深缩放转场、框选/Shift 连选/拖到文件夹或面包屑移动、右键与长按菜单、新建/重命名/移动/复制/删除（FLIP 过渡）、属性与直链、离线下载、文件夹密码。
- 分享：右键或选择后生成链接（有效期、提取码、访问次数），带二维码；访客打开 `/@s/<id>` 无需登录；账户菜单里的「我的分享」可停用或删除。
- 影院模式：顶栏第三个视图，大幅海报位随机推荐（每次进入换一部，有剧照的优先，每 12 秒轮换，指针停在上面时暂停，「换一部」手动换），悬停海报时跟随悬停的条目；继续观看一行，海报墙。
- 播放器字幕：自动加载和视频同名的 .ass/.ssa/.srt/.vtt（文件夹里只有一个视频时取全部字幕），经 /p 同源读取，UTF-8/UTF-16/GB18030 自动识别；ASS 用 ASS.js 渲染保留样式（按需加载），SRT/VTT 自绘；字幕菜单可切换、关闭（记住）、±0.5 秒微调时间轴，C 开关字幕。
- 下一集：一集放完弹出下一集（按文件名自然顺序），8 秒倒计时自动播放，可取消；控制栏「下一集」按钮，Shift+N；全屏尽量延续。
- 观看进度跨设备：进度按用户存在服务器 `data/tgvio/progress.json`（`/api/tgvio/progress`），浏览器先写本地、5 秒后或页面隐藏时上传、打开网站或切回标签页时拉取，逐条合并新的为准；看完保留为「已看完」，海报显示标记。
- 片库：顶栏「片库」（`/@library`），从海报记录汇总所有认出的电影、剧集（`/api/tgvio/library`，不请求网盘），按当前用户权限过滤（有密码的文件夹不出现），去掉装片子的上级文件夹和 Subs/花絮这类附属文件夹；搜索片名或原名、分类、按最近添加/评分/年份/名称排序。
- 全站搜索：不开 OpenList 索引（会爬 115）时，顶栏搜索走 `/api/tgvio/search`：文件名来自打开过的文件夹（目录列出钩子写入 `data/tgvio/names.json.gz`，最多 40 万条，目录删掉的子树随之清掉），片名来自海报记录（中文名、原名都能搜到），同样按权限过滤。
- 剧集详情：剧集或季文件夹顶部显示剧照、简介、评分、「继续看/开始看 第 N 集」，季文件夹列出 TMDB 的每一集（剧照、集名、简介、看完标记，没有文件的标「未下载」），剧的根目录列出各季并指向季文件夹（`/api/tgvio/series`，TMDB 详情、季、分集缓存半天）。片库顶部「继续观看」取跨设备进度。
- 转存 115 分享：115 文件夹的上传菜单或命令面板里「转存 115 分享」，粘贴链接（支持 ?password=、提取码文字、#提取码），浏览分享里的文件夹，勾选后由 115 直接复制到当前文件夹（`/api/tgvio/115/share/peek|save`，需要写权限）。
- 在线字幕：管理 › 海报 里填射手网(assrt.net)令牌（只写不读，`data/tgvio/assrt_token`），播放器字幕菜单出现「在线搜索字幕」：先按文件名匹配，也可以输入片名集数，选中后保存为 `视频名.语言.扩展名`（不覆盖已有文件），播放器马上切到它。免费额度每分钟 20 次，服务端限速。`TGVIO_ASSRT_BASE` 仅供测试替换接口地址。
- 手机和电视：锁屏/通知栏显示片名和画面，可播放暂停、快进快退、拖动、下一集（Media Session）；有可用设备时控制栏出现投屏按钮（AirPlay / Chrome 投屏）；可「添加到主屏幕」全屏使用，图标是站点标志的 PNG（`/tgvio/icon/192.png|512.png|maskable.png|apple-touch-icon.png`）。
- 排序和分类：名称、时间、大小之外，文件夹里有 TMDB 海报时多出「评分」「年份」（按 TMDB，同年按评分，没配上的排最后）；一个文件夹里不止一类时出现分类筛选：电影、电视剧、动漫（TMDB 动画类型）、综艺（真人秀、脱口秀、新闻类剧集）、纪录片，带数量。分类存在海报记录的 `cat`，旧记录在后台按 TMDB 详情补上。
- 文件夹封面：网格视图里文件夹显示里面图片拼成的封面，悬停时轮换。
- 找资源：设置 › 影视库 › 资源搜索 打开后，「默认保存位置」那个文件夹（没设就是影视库第一个生效目录）的标题旁和 Dock 出现「找资源」（`hooks/useResourceRoot.ts`，弹窗走 `Dialogs` 的 `resources`）。站点存 `data/tgvio/resources.json`（名称 + 含 `{q}` 的搜索地址），默认在用户浏览器里打开搜索页，用户复制磁力回来粘贴（纯文本、复制的网页片段里的 `<a href="magnet:">`，或「送回影视库」书签把整页磁力放进 `<默认保存位置>#resources=`，# 不经过服务器）。每个站点可选「服务器直接读取（SeedHub）」：`/api/tgvio/resources/titles|seeds|magnets` 由服务器读搜索页、资源列表，只为要下载的资源取磁力（页面里 base64 的 `data`），400 ms 一次、缓存 10 分钟；遇到人机验证报错，换回浏览器打开即可。磁力按中字 > 国语/粤语 > 清晰度排序（`tgvio-web/src/lib/magnets.ts`），勾选后选文件夹，交给该网盘自己的离线下载；每部片在默认保存位置下建「片名 (年份)」文件夹（取 TMDB，配好海报），一次选多部时外面再套一个「xx 系列」文件夹，文件到了以后文件夹顶部提示「按 TMDB 整理命名」。探活：管理端 `/api/admin/tgvio/resources/probe`（正常 / 有人机验证 / 打不开），用户端按钮旁的小圆点表示这台设备能否打开该站。
- 触屏：手机和平板（`pointer: coarse`）上按钮、输入框、菜单项、开关至少 44px，iPad 多选后 Dock 有「更多」；横屏手机看视频铺满全屏；安卓全屏时宽屏视频自动转横屏；海报和文件长按是多选，不弹 Safari 的图片菜单。
- 影视库范围：设置 › 影视库 的「生效目录」决定海报、剧集详情、按 TMDB 整理命名、片库、片名搜索、视频缩略图在哪里起作用；目录外服务端一律不做（`TMDB.InLibrary`），前端按 `/api/tgvio/library/scope` 隐藏入口。
- 海报：文件夹和视频按片名自动配 TMDB 海报（网格封面、影院模式大图与简介），右键「更换封面」手动挑选（剧集可选到具体一季）。季文件夹（第一季、Season 01）用所在剧的季海报，剧集单集文件和番号不单独查。管理 › 设置 › 海报：生效目录（只在这些文件夹里找海报，可多个）、开关、令牌（只写不读，存 `data/tgvio/tmdb_token`，权限 600，不进仓库）、测试连接、语言、海报是否跟随封面模糊、匹配统计、没配上的名字（点名挑海报、× 标为不需要）、重新匹配、清空图片缓存。开关和语言存在 `data/tgvio/tmdb.json`。
- 只放了一部片的文件夹（文件夹名和片名不一样，比如「最后孤岛」里是「最后孤屋」）沿用那部片的海报；整套合集（「[周星驰] [原盘电影集]」）用里面几部片的海报拼封面；只由方括号组成的名字（「[大话西游][1-2集][1994-1995]…」）取第一个有意义的方括号当片名；ISO 也查海报。
- 按 TMDB 整理命名：文件夹右键（或文件夹空白处右键）「按 TMDB 整理命名」。电影改成「片名 (年份).扩展名」，剧集改成「剧名 - S01E29 - 集名.扩展名」（集数按 TMDB 的分季对齐，字幕组的连续编号会换算），字幕和 .nfo 跟着视频改，文件夹改成「片名 (年份)」或「剧名 第二季 (年份)」；多选（含全选）后在 Dock 或右键里也能用：选中的文件夹各自整理，选中的文件每个按自己的片名（剧集按集数）改，所在文件夹的名字不动；一个文件夹里有几部电影时各按各的名字，文件夹不动。子文件夹一起整理（`/api/tgvio/rename/tree`，最多 4 层、80 个含视频或字幕的文件夹）：季文件夹按自己的名字认季（「第五季」「S02」），认不出东西的子文件夹（Subs、花絮）跟随上级的剧或电影、名字保留；对不上视频的字幕按自己的集数命名，没有集数就用上级的片名，保留 .chs 这类语言标记；剧有好几季、文件夹名和文件名都没说是哪季时，这个文件夹停下来等人选季，其余照常。先列出改名计划，逐条勾选后才改，一条一个请求、按顺序改，海报记录跟着新名字走（`server/handles/tgvio_rename.go`、`internal/tgvio/rename.go`）。执行时先改最深的子文件夹，最后改上级。
- 视频缩略图：115 列表不给视频图片。认得出是哪部剧的单集文件用 TMDB 的单集剧照（不碰 115，不模糊）；其余视频由服务器取 115 云端转码最小清晰度里约五分之一处的一段（最多 5 分钟处），用 ffmpeg 截一帧，存 `data/tgvio/thumbs/`，永久缓存（文件大小或修改时间变了会重新截）。只为在屏幕上出现过的视频排队，一次一个，每小时约 300 张，115 熔断打开时暂停；没有云端转码的视频 3 天后再试（`internal/tgvio/thumbs.go`、`server/handles/tgvio_thumb.go`）。需要系统里有 ffmpeg。
- 挂载 115 文件夹：存储页「挂载 115 文件夹」借一个已登录的 115 存储的账号，点进网盘里的文件夹直接挂载，新存储复制它的登录和设置（Cookie 不经过浏览器）；编辑 115 存储时「根文件夹 ID」旁边可以「在网盘里选」。文件夹列表每次点击一次 115 列表请求，结果缓存 2 分钟，走统一限速（`server/handles/tgvio_mount.go`）。
- 登录设备：每次登录是一台设备，存在 `data/tgvio/sessions.json`，重启不掉线；一直在用就一直有效，闲置超过设置 › 登录里的天数（默认 90 天）才要重新登录。账户资料里看自己的设备、退出某台或其他全部；管理员在用户编辑里看和退出任何人的设备。
- 断点续传：32 MB 以上的文件先分块落到服务器 `data/tgvio/staged/`，关掉浏览器或服务器重启都不丢；再选同一个文件只补传缺的块，3 天没动静自动清理。传完由服务器任务推到网盘。
- 多个根目录：用户的「根目录」可以一行一个，他的首页把它们并排列成文件夹（网页可用；WebDAV 仍只认单个根目录）。
- 强制刷新：右键文件夹或 Dock 的刷新会重读网盘并提示结果；登录用户都能用，同一文件夹 5 秒最多一次。
- 回收站清理：115 账户设了安全密钥时，清理前要输入 6 位安全密钥（只在本次浏览中记住）。
- 管理员文件夹密码：用户页或元信息页的「在网页里也输入文件夹密码」，只影响网页，WebDAV 不变。
- 云端转码播放：115 的视频默认用网盘自己的 HLS 转码（4K、1080P 等，H.264），服务器代取分片；清晰度菜单可切回原画。每个视频只多一次主列表和一次清晰度列表请求，各缓存 30 分钟，走 115 的限速与 405 熔断。
- 视频：网盘链接慢时有加载提示，浏览器放不了时给出外部播放器（Infuse、nPlayer、VLC、IINA、PotPlayer），记住进度续播；预览里滚轮切换文件。
- 压缩包：在预览里直接浏览 zip/rar/7z/tar 目录、打开或下载单个文件、带密码的压缩包、解压整个或当前文件夹到任意目录（服务器任务）。
- 预览：图片（从格子放大展开、双击/滚轮/双指缩放、左右滑动、下拉关闭、缩略图条）、视频、音频、文本/代码/Markdown；其他类型给下载。
- 上传：拖入窗口或选择文件/文件夹；16 MB 以上走 `/api/fs/multipart`（分片并发 3、单片重试、断线续传），其余 `/api/fs/put` 作为任务；传输面板含服务器任务。
- 搜索面板（`/` 或 Ctrl K）：当前文件夹模糊筛选、全局搜索（需开启索引）、命令。
- 管理（`/@manage`）：概览（115 空间、访问统计、回收站清理）、存储（按驱动定义生成表单）、用户与权限、元信息、设置、任务。
- 登录页：倾斜的电影海报墙（海报由代码绘制，不加载外部资源、不展示网盘内容），列交替上下滚动、随指针倾斜，登录后整面墙推近淡出；设备跟不上 60 fps 时自动改为静止。
- 手机：长按进入多选（再长按出菜单）、菜单改为底部操作表、双指捏合切换 2/3/4 列、下拉刷新、输入框 16px 防 iOS 放大。
- 封面默认模糊（悬停/长按显示，搜索面板可切换）；深浅主题跟随系统；`prefers-reduced-motion` 时关闭动效。

## 构建

```sh
bash tgvio/build.sh                      # 默认嵌入 tgvio-web（先跑 tsc、vitest、vite build）
TGVIO_UI=official bash tgvio/build.sh    # 改嵌官方前端 v4.2.6
```

需要 Go（/usr/local/go）、Node（/root/.local/bin）与干净的工作区。输出 `/root/build/openlist-tgvio/openlist-<commit>`；官方前端同时解压在 `/root/build/openlist-tgvio/web/official-v4.2.6/`，在 `data/config.json` 设 `"dist_dir"` 指向它并重启，即可不换二进制切回官方界面（清空 `dist_dir` 再重启切回）。

## 升级（只换二进制）

```sh
bash tgvio/upgrade.sh /root/build/openlist-tgvio/openlist-<commit>
```

备份当前二进制到 `/root/backup/openlist-upgrade-<时间>/`，替换后核对目录列表、读写删与批量删除（`probe.py` 在 tgvio-player 容器内以 Player 账号执行）；任一失败自动换回旧二进制。

## 回滚

```sh
systemctl stop openlist
install -m 755 /root/backup/openlist-upgrade-<时间>/openlist.previous /opt/openlist/openlist
systemctl start openlist
```

## 部署事实

- 本机到 115 上传端（OSS 深圳，80 端口）RTT 约 216 ms、丢包约 5%，单连接上限约 1.8 Mbps，且分片须按序上传；宿主机已改用 BBR（`/etc/sysctl.d/90-tgvio-bbr.conf`），30 MB 上传 744 s → 274 s。秒传命中的上传不受影响。
- WebDAV PUT 任何失败都会被 OpenList 报成 405；客户端断开不会中止上传（期间对同一路径的 PUT 得到 423）。
